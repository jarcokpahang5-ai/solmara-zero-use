This entry is exactly one original line describing a hilariously useless superpower: the power to stop time, ruined by a three-second limit, a once-a-day cap, and a trigger that only fires mid-sneeze. It was written for the make.fun bounty "One Line, Zero Use: The Useless Superpower Sprint" ($5 in USDC), where a judge compares lines on how funny, how fresh, and how neatly worded they are.

## Run it

```bash
python3 main.py
```

This prints the line and writes it to `/output/entry.txt`.
